# unfclip · 낯선클립

낯선마케팅의 장기요양기관용 모바일 반응형 원페이지 영상 제작 도구.

## 실행

Node.js 22 이상. `npm ci`, `npm run build`, `npm start`.
`npm test`는 문구, 장면 길이, 수동 가림 보간, 로그 허용 필드를 검사합니다.
Render: Node web service, Singapore, build `npm ci && npm run build`, start `npm start`, health `/api/health`.

## 구현

- 브라우저 내 MediaPipe 얼굴 탐지(영상 초당 6회), 인접 결과를 넓게 가림. 얼굴 검출 완전성은 보장하지 않음.
- 수동 모자이크 영역, 적용 시간, 시간별 위치 보간, 가까운 검출 얼굴 따라가기. 사람이 겹치면 수동 검수 필수.
- 사진/영상 혼합, 순서/삭제, 구간 선택, 전체 보이기/화면 채우기, 기관명/전화번호/로고.
- 활동 분류별 문구, 편집 가능한 게시글 및 태그: 외부 생성형 AI API 없음.
- 한글 폰트, 색상, 크기, 배경 그라데이션, 그림자, 외곽선, 영상 마지막 문의 화면.
- WebCodecs + Mediabunny를 통한 MP4 H.264 출력, 선택 시 AAC 오디오. 1080p/720p, 최대 60초.
- 촬영 소리 기본 끄기, 직접 합성하는 배경 멜로디 2종.
- 최종 파일 확인, 수정 복귀, 다운로드 및 지원 기기 파일 공유, 표지 저장.
- 기기 내 설정 기억(선택), 공개 샘플, 카카오톡/홈페이지 상담, 도구 공유.

## 개인정보와 로그

미디어/얼굴 좌표/기관명/전화번호/파일명/활동 문구는 서버로 전송하지 않습니다.
Express에는 미디어 업로드 API가 없습니다. `/api/events`는 JSON 2KB 제한이며 서버에서 이벤트와 필드를 재검증합니다. 고정 이벤트명, 오류코드, 임의 작업번호, OS/브라우저 종류, 파일 수/용량 구간, 처리 시간 등만 표준 출력에 기록합니다. 요청본문/헤더/IP/스택은 앱에서 기록하지 않습니다. Render의 인프라 접속 로그는 별도 정책 적용.
운영자는 Render Logs에서 작업번호로 필터링합니다. 화면에 표시된 8자리 번호는 로그의 job 값 접두사입니다. 저장 요청과 사용자의 저장 확인은 별도 이벤트입니다. 상담 클릭은 상담 접수로 해석하지 않습니다. 세션 재생이나 스크린샷 수집은 없습니다.
원본과 완성 MP4는 메모리에만 보유합니다. 새로고침/탭 종료 후 원본은 다시 선택해야 합니다. 설정 기억을 선택했을 때만 텍스트 설정을 localStorage에 보관합니다. 로고는 보관하지 않습니다.

## 지원 범위와 한계

최신 Safari/Chrome 권장. 실제 기기 코덱 지원을 먼저 확인하며 지원하지 않는 기기에 MP4 저장을 약속하지 않습니다. 최대 12개, 합계 300MB, 개별 원본 영상 180초, 사진 50MP 제한. 원본 영상은 처음 15초가 기본 선택되며 사용할 구간을 조정할 수 있습니다. 처리 중 화면 유지 필요. 자동 모자이크 누락과 추적 대상 전환 가능성이 있으므로 전체 영상 최종 검수 필수. 네이버 자동 게시 기능은 없으며 이용자가 저장한 영상을 직접 게시합니다. 공식 플랫폼 정보태그는 별도 선택해야 합니다.

## 배포 및 라이선스

얼굴 모델과 WASM은 빌드 때 공식 배포처/고정 버전 패키지에서 받아 같은 출처에서 제공합니다. 런타임에 미디어를 외부 AI로 전송하지 않습니다.
폰트: Noto Sans KR, Noto Serif KR (SIL OFL); MediaPipe (Apache-2.0); Mediabunny (MPL-2.0); Lucide (ISC). 배경음악은 코드로 합성한 단순 멜로디입니다. Render 무료 플랜은 비활성 시 절전되어 첫 연결이 지연될 수 있습니다.
